# /assets/images

Drop your portfolio images here. Recommended naming convention:

## Profile
- `profile.jpg` — Your headshot (used in the About section)
  Recommended: 400×400px, square crop, good contrast against dark bg

## Homepage Work Cards (used in the case study thumbnail grid)
- `thumb-onetrust.jpg`      — OneTrust design system screenshot or Figma frame
- `thumb-schlage.jpg`       — Schlage.com redesign screenshot
- `thumb-healthcare.jpg`    — Healthcare / DMI project visual
- `thumb-perq.jpg`          — PERQ platform screenshot

  Recommended size: 800×600px (4:3 ratio) — will be cropped to fill card

## Case Study: OneTrust
Place inside `/assets/images/onetrust/`:
- `audit-matrix.jpg`        — Component audit spreadsheet / Figma table
- `pendo-analysis.jpg`      — Pendo heatmap or analytics dashboard screenshot
- `token-architecture.jpg`  — Figma Variables / token hierarchy screenshot
- `component-library.jpg`   — Figma component library overview
- `storybook.jpg`           — Storybook screenshot
- `ai-prototype.jpg`        — Figma Make / AI prototype workflow screenshot
- `production-framework.jpg`— AI governance checklist or framework doc

  Recommended size: 1200×800px minimum

## Tips
- Export from Figma at 2x for crisp retina rendering
- Use JPG for photos/screenshots (quality 85), PNG for graphics with transparency
- Keep individual files under 500KB — compress at squoosh.app if needed
