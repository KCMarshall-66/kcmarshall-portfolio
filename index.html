about

A designer who commits code.

I’ve spent 15+ years designing complex enterprise interfaces and 10 in design technology. Today I lead UX for OneTrust’s Privacy Management domain, where I run the org’s shift to AI-assisted design: prototypes built with Claude Code, Devin and v0, kept in Git repositories and merged through pull requests so AI-generated work is reviewed like any other.

I also author AI skills for domain work — like a ROPA authoring skill — and audit every design against WCAG and Section 508 in Figma and again after build.

What I bring to an interactive team

  • Complex, stateful prototypesRule builders, matrices, roadmaps and dashboards with real logic — not click-throughs.
  • Code fluencyHTML, CSS and TypeScript; comfortable in pull requests and merges.
  • AI-native workflowClaude Code, Claude Cowork, Devin, v0 and Figma Make — plus authoring AI skills.
  • On-system by defaultFigma Variables, design tokens, component libraries and Storybook.
  • Accessible from the startWCAG and Section 508 checks in Figma and again after build.
  • Validated before buildMaze testing and Pendo analytics to prove the interaction works.
